# Arcade Hub

A lightweight static gaming site featuring Tic-Tac-Toe and Snake, with a local leaderboard.

## Run locally

Use any static server. Examples:

- Python 3: `python3 -m http.server -d . 5173` then open `http://localhost:5173/gaming-site/`
- Node: `npx serve .` then visit `/gaming-site/` path.

## Deploy

Host the `gaming-site` folder on any static host (GitHub Pages, Netlify, Vercel).
